# Gate Template

Gate is a product that handles authentication and security management along environments, this product
provides users, permits, and really secure authentications to provide other products authenticate permits
and external services communication.

## **Solutions**

### (**View**) [Gate View](./solutions/gate_view/gate_view_README.md)

Solves the need to represent the [Gate] business, providing user-friendly
interaction with security management operations.

### (**Server**) [Gate Server](./solutions/gate_server/README.md)

Solves the need to handle, process and apply business logic for [Gate] product. Handles authentication processes, permits management, and security business topics, it is a security management shaped server.

### (**Client [*dart*]**) [Gate Server Client](./solutions/gate_server_client_dart/README.md)

Solves the need to connect a view-side language framework with [Gate Server](#server-gate-server)
